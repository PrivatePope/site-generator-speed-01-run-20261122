# sitegen-fast

A faster drop-in for makefun-site 1.0.0: byte-exact static-site builds, ranked by CPU time.

Entry for the make.fun bounty [Build a static site faster, 22 November 2026](https://make.fun/bounty/site-generator-speed-01-run-20261122) — $100, 10 places.

## Run

`node main.ts` reads every case from `/input/cases.json`, answers each with `run` from `solve.js`, and writes `/output/answers.json`. Node 22 and its standard library only; nothing is installed.
